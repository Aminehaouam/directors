# Jack of All Trades (5 s sting)

A HyperFrames video, 1920×1080, 30 fps, 5 s. No voice and no music, sound effects only.

An empty workshop shadow board fills with tools from every trade: saw, hammer, wrench, paintbrush, whisk, scissors, tape measure, roller, screwdriver, spatula, pliers, level, trowel, stethoscope and ladle. They land faster and faster, each with a metal clank, over a rising riser. A yellow sign, JACK OF ALL TRADES, slams onto its pegs and rattles the whole board. A strip of masking tape gets slapped on: MASTER OF NONE. Red marker strikes NONE and writes MANY.

Output: `renders/jack-of-all-trades.mp4`

```bash
npm run check     # lint, layout, motion, audio
npm run dev       # preview in the browser
npm run render    # render an MP4 to renders/
```

- `index.html`: root (5 s), mounts the scene and places every sound one frame after its picture.
- `compositions/board.html`: the scene. It is generated by `scripts/gen-board.py`, so change layout or timing there and regenerate. Copy is in the scene's variables (`line1`, `line2`, `label`, `struck`, `fix`).
- `scripts/prep-audio.sh`: cuts the raw downloads in `.media/audio/sfx/` into the takes in `assets/sfx/`.
- Credits and licences: `assets/sfx/CREDITS.md`.
