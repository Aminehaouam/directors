# Decisions

**Stack: Node 22 + Playwright (Chromium) deterministic frame capture of a Canvas 2D scene graph, ffmpeg 6.1 for assembly.** Chosen from docs/ENVIRONMENT.md: Playwright and Chromium, ffmpeg with libx264/aac/prores_ks, 4 cores, npm and Google Fonts reachable. No GPU, so Canvas 2D (software raster) is used rather than WebGL.

- **Pure function of time.** No rAF, Date.now, Math.random, CSS animation or live video decode; seeded mulberry32 keyed by element id; footage pre-extracted to JPEG sequences. Verified by hashing frames 0/450/899 across fresh pages (`npm run validate`, `npm test`).
- **Canvas over SVG/DOM.** Multiply/screen blending, per-layer parallax and offscreen buffers for transitions are direct in Canvas; SVG is used for authored illustrations (editable files in public/illustrations, generated by a seeded script).
- **Events reference cues, not seconds.** Re-timing the recording edits only cue start/end; word markers are fractions of a cue.
- **Fonts vendored** (@fontsource woff2, OFL) and loaded with FontFace; failure names the font.
- **Fallback: @napi-rs/canvas** would run the same scene graph in Node if no browser can be installed (not implemented; scenes use only Canvas 2D API).
- **Trade-offs:** PNG frames are large (~1-3 GB at 1080p) but lossless and resumable; ffmpeg `loudnorm` is single-pass; the footage's own audio is optional (`useAudio`).
- **Brief inconsistency handled:** the brief ties the four diagram lines to words in line 3, but shot 6 begins after "Rewards." So the four lines land on "reasons / never / to / ask"; change the `atWord` values in `events` to retarget.
