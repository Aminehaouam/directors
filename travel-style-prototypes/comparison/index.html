One ticket, three worlds

The same Rive scene in three art directions. A journal opens, a ticket slides out and becomes a miniature London, Big Ben rises, Coco lands and nudges the ticket, and it opens into a map to Paris. Composition, timing, actions and camera are identical; only the art changes.

A

Modern Illustrated Travel Journal

Strengths

  • Clean, brand-ready editorial look. The type and landmarks stay crisp at any size.
  • The cheapest to extend: a new city is a new vector set on the same rig and timeline.
  • Nearly all of it is native Rive vector art, so the same files could run live in an app or on the web.

Limitations

The flattest of the three. Depth comes from soft shadows, not material, so it needs a disciplined palette to stay distinctive.

Implementation complexity

low–medium
B

Dimensional Paper Cut-Out

Strengths

  • The most tactile and premium. Fibres, cut edges and stacked shadows make a paused frame look photographed.
  • Pop-up motion (rising, folding, unfolding) fits the material naturally.
  • Feels handmade, which suits a warm learning brand.

Limitations

Depth is simulated in 2D, with no true perspective or parallax. The paper treatment lives in the compositor, not in Rive, so it can't run live from the .riv alone. Renders about twice as slowly as A. A final film would benefit from a 2.5D or real-3D camera pass.

Implementation complexity

medium–high
C

Modern Pixel Art

Strengths

  • The most distinctive and youthful. It reads as a game, which suits a learning adventure.
  • A locked 41-colour palette and a fixed 4× pixel grid keep every scene consistent.
  • Tiny files (under 4 MB for the full preview).

Limitations

Handwriting and small print have to become pixel glyphs. Rive draws vectors and the pixel look comes from a quantise step, so camera zooms re-rasterise and edges shimmer slightly. A final film should pan on whole pixels and use hand-pixelled sprites for Coco and Big Ben.

Implementation complexity

Rive

Each direction is one .riv file with eight artboards and seven state machines (journal, ticket and map, three London layers, Coco). Coco's machine has two layers: a flight path, plus poses for fly, land, idle, nudge and cheer.

Rendering

The official Rive runtime renders every element frame by frame on a fixed 30 fps clock. A small compositor adds the shared camera and each style's finishing: grain and shadow (A), fibre, cut edges and depth of field (B), or palette quantising and the 4× pixel grid (C).

Editable sources

The Rive editor has no command-line authoring, so the .riv files are generated from readable source (art, timing and motion per element) and rebuilt with one command.
